# Passenger van source

`passenger_van.glb` is the **Car DNA** derivative of Innerscene's Passenger Van with Side Windows; high roof adapted to a lower-roof minivan. Source model: https://www.innerscene.com/tools/library/3d-parts/passenger-van-with-side-windows-474dd4a2 (listed CC0); derivative: https://github.com/Wenhuaren5/car-dna/blob/ed01c3e6870f0b3a781116699b1b5c269982d9a2/public/models/minivan.glb, provenance at https://github.com/Wenhuaren5/car-dna/blob/ed01c3e6870f0b3a781116699b1b5c269982d9a2/src/components/glbCarModel.js. Downloaded unmodified here. Approx. 147,492 triangles; 391 mesh nodes in Godot. Not performance-tested on iPhone. It is a temporary static lead vehicle, not driveable; damage and blue tarp referenced by dialogue are not yet represented in the model.
