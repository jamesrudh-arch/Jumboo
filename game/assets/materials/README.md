# Physical material source and license

Two CC0 Poly Haven materials, downloaded without resizing/recompression from community mirrors on 25 November 2026. The mirror supplies 2K maps; this is not a claim that 2K is Poly Haven's highest available resolution. No 1K downsampling was performed. Files include base color, OpenGL normal, and roughness; displacement and AO are not currently used. In-game materials and lighting still require visual review.

- Brown Planks 03, Rob Tuytel, https://polyhaven.com/a/brown_planks_03 — files from https://github.com/zuujis-cc0/polyhaven-textures-wood/tree/f05c7edfe1f7c7a88ede052ad82093f87498b760/brown_planks_03/2k
- Concrete Floor Worn 001, photography Dimitrios Savva, processing Rico Cilliers, https://polyhaven.com/a/concrete_floor_worn_001 — files from https://github.com/zuujis-cc0/polyhaven-textures-concrete/tree/aec5170acc4bcfe672a09f5103e2bb5f016db73d/concrete_floor_worn_001/2k

Source license: https://polyhaven.com/license (CC0). The scene's wet road uses the concrete material with lower roughness; that does not add rain, puddles, or true screen-space reflections.
