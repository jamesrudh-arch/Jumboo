# Interim character asset provenance

The playable blockout uses modified CC0 assets by Quaternius. They are **temporary stock assets, not the original Marcus design or approved final art**.

- `body_m.glb`: Universal Base Characters, https://quaternius.com/packs/universalbasecharacters.html (creator describes the kit as CC0).
- `outfit_m.glb`: Modular Character Outfits – Fantasy, creator license in `LICENSE-Quaternius-Outfits-CC0.txt`.
- `anims.glb`: Universal Animation Library, https://quaternius.com/packs/universalanimationlibrary.html; creator notice in `LICENSE-Quaternius-UAL-CC0.txt`.
- These three source files were retrieved from the GitHub mirror https://github.com/shonejj/WorldapocalypticRetrogame/tree/5b01ec96d5dac156536de4862f5ebb3eb082dd03/public/models/chars on 25 November 2026. The mirror's labels and the creator's pages/pack notices identify these as CC0. No warranty of suitability or visual quality is implied.
- The two `*_animated.glb` files combine matching named skeletons with the animation tracks, generated by `tools/merge_character_animations.py`. Materials are recolored at runtime. They retain the CC0 source rights.
- These are provisional assets. The outfit is a fantasy stock outfit recolored for the blockout, not an authored contemporary Marcus outfit. No performance, appearance or device acceptance is claimed.
