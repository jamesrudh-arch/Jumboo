# Interim rigged human models

`andre_casual.glb`, `aisha_formal.glb`, and `carlos_casual.glb` are the unmodified exports from Avatar Studio, https://github.com/memoriesrohit/avatar-studio/tree/2fd9ec82fbe1613d40ae38aadcca3f410725f740/models. The author attributes the characters and motion-capture clips to the Microsoft Rocketbox Avatar Library, licensed MIT; the required Microsoft notice is in `LICENSE.md`. These files are stock interim casting and do not establish final Marcus, Sade or collector designs. They contain multiple overlapping outfit variants; code selects the original. Idle/walk/talk/phone are supplied, but no actual punch, hit, or authored phone pickup clips are included. Godot 4.7.2 headless import was tested; Xogot version compatibility, rendering, animation quality, device performance and skin appearance are not yet verified.
