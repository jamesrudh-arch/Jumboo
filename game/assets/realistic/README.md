# Grounded environment sources

Downloaded without reducing source resolution from the following CC0 Poly Haven mirrors on 25 November 2026. The mirrors supply 2K textures; Poly Haven also offers higher resolutions. These are interim scene assets, not a finished city.

- `wooden_table_02`: Wooden Table 02 by Serhii Khromov, https://polyhaven.com/a/wooden_table_02; https://github.com/zuujis-cc0/polyhaven-models-furniture/tree/0690e2bccd36ce8182c2407966d357f056661804/wooden_table_02/2k. Original glTF, binary, and three 2K textures.
- `modular_factory_facade`: Modular Factory Facade by James Ray Cock, https://polyhaven.com/a/modular_factory_facade; https://github.com/zuujis-cc0/polyhaven-models-architecture/tree/06c6a289e147bc3990d1ef1138adf62ffcffb968/modular_factory_facade/2k. Original glTF, binary, and referenced 2K textures. Game code assembles a small set of kit pieces, not the complete laid-out library.

License: https://polyhaven.com/license (CC0). Placement, lighting, performance and rendered appearance have not been verified on a physical device.
