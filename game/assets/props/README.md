# Interim environment asset provenance

These CC0 assets are temporary stock dressing, not an approved final environment. Downloaded from the mirror https://github.com/shonejj/WorldapocalypticRetrogame/tree/5b01ec96d5dac156536de4862f5ebb3eb082dd03/public/models/props on 25 November 2026; the mirror says they have been simplified and use 512px WebP textures.

- `wooden_crate.glb`: Wooden Crate 01, James Ray Cock, https://polyhaven.com/a/wooden_crate_01
- `tyre.glb`: Old Tyre, MP, https://polyhaven.com/a/old_tyre
- `hanging_lamp.glb`: Hanging Industrial Lamp, Kuutti Siitonen, https://polyhaven.com/a/hanging_industrial_lamp

Poly Haven's asset license is CC0: https://polyhaven.com/license. The three models were imported in Godot 4.7.2 headless on Linux, but their appearance and mobile compatibility have not yet been visually validated.
