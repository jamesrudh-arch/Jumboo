# Interim environment asset provenance

These CC0 assets are temporary stock dressing, not an approved final environment. Downloaded from the mirror https://github.com/shonejj/WorldapocalypticRetrogame/tree/5b01ec96d5dac156536de4862f5ebb3eb082dd03/public/models/props on 25 November 2026; the mirror says they have been simplified and use 512px WebP textures.

- `wooden_crate.glb`: Wooden Crate 01, James Ray Cock, https://polyhaven.com/a/wooden_crate_01
- `tyre.glb`: Old Tyre, MP, https://polyhaven.com/a/old_tyre
- `hanging_lamp.glb`: Hanging Industrial Lamp, Kuutti Siitonen, https://polyhaven.com/a/hanging_industrial_lamp
- `covered_car.glb`: Covered Car, MP, https://polyhaven.com/a/covered_car
- `generator.glb`: Portable Generator, James Ray Cock, https://polyhaven.com/a/portable_generator
- `jerrycan.glb`: Metal Jerrycan Green, Ulan Cabanilla, https://polyhaven.com/a/metal_jerrycan_green
- `barrel.glb`: Barrel 01, Jorge Camacho, https://polyhaven.com/a/Barrel_01
- `road_barrier.glb`: Concrete Road Barrier 02, Amal Kumar, https://polyhaven.com/a/concrete_road_barrier_02
- `aircon_unit.glb`: Exterior Aircon Unit, Monsta3D, https://polyhaven.com/a/exterior_aircon_unit
- `plastic_crate.glb`: Plastic Crate 02, Fabi_G, https://polyhaven.com/a/plastic_crate_02

Poly Haven's asset license is CC0: https://polyhaven.com/license. These models have been imported in Godot 4.7.2 headless on Linux, but their appearance and mobile compatibility have not yet been visually validated.
